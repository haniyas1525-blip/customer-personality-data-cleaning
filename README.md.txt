# Customer Personality Data Cleaning & Preprocessing

## Project Overview

This project focuses on cleaning and preprocessing a customer personality dataset using Python and Pandas.

The objective was to identify and correct common data quality issues and prepare the dataset for further analysis.

## Dataset

The dataset contains customer information including:

- Customer ID
- Year of Birth
- Education
- Marital Status
- Income
- Number of Children
- Number of Teenagers
- Customer Registration Date
- Country
- Spending Information

## Data Cleaning Performed

The following preprocessing techniques were applied:

- Identified missing values
- Handled missing numerical values using median
- Handled missing categorical values using mode
- Removed duplicate records
- Removed unnecessary spaces from text
- Standardized categorical values
- Converted date values to datetime format
- Corrected numerical data types
- Performed before-and-after data quality validation

## Data Quality Improvement

The dataset was checked before and after preprocessing to verify that missing values and duplicate records were successfully handled.

A visual comparison was also created to demonstrate the improvement in data quality.
